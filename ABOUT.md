# What is CORE?

CORE (Center Outlook Reminders) sits quietly in your Mac's menu bar and watches for Microsoft Outlook meeting reminders. When Outlook shows a reminder saying your meeting is starting now or within your selected lead time, it moves that popup to the centre of your screen so it can't hide behind other windows.

CORE checks for reminder windows on a repeating interval, measured in seconds. The default is 10 seconds, and you can change it from the menu using "Change Check Interval" (allowed range: 1 to 300 seconds).

You can also choose when centering should begin using "Change Reminder Lead Time". Set it to 0 for "Now" only, or any value from 1 to 30 minutes. The default lead time is 2 minutes.

Once set up, it runs automatically in the background every time you log in, and you can control it at any time from the small "CORE" icon in your menu bar.
